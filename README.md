# Hive → BigQuery DDL Migration

Converts all Hive schemas from the Acme Cloudera ecosystem to BigQuery DDL across 4 datasets (100 tables + 15 views = 115 SQL files).

## Dataset Summary

| Dataset | BQ Project | Tables | Views | Location |
|---------|-----------|--------|-------|----------|
| `raw` | `acme-analytics` | 19 (17 source + 2 Avro net-new) | 2 | US |
| `staging` | `acme-analytics` | 10 | 1 | US |
| `retail` | `acme-analytics` | 58 (42 source + 12 dim net-new + 4 Kudu snapshots) | 11 | US |
| `regional_eu` | `acme-analytics-eu` | 13 | 1 | EU |
| **Total** | | **100** | **15** | |

## Type Mapping Rules

| Hive Type | BigQuery Type | Notes |
|-----------|--------------|-------|
| `TINYINT` / `SMALLINT` / `INT` | `INT64` | BigQuery has no narrow integers |
| `BIGINT` | `INT64` | Direct mapping |
| `BOOLEAN` | `BOOL` | BigQuery keyword |
| `FLOAT` / `DOUBLE` | `FLOAT64` | BigQuery universal float |
| `DECIMAL(p,s)` | `NUMERIC(p,s)` | Preserves precision constraints |
| `STRING` | `STRING` | Direct mapping |
| `TIMESTAMP` | `TIMESTAMP` | Interpreted as UTC |
| `DATE` | `DATE` | Direct mapping |
| `MAP<STRING,STRING>` | `JSON` | 10 columns across all datasets |
| `STRUCT<...>` | `STRUCT<...>` | Sub-fields widened per rules |
| `ARRAY<...>` | `ARRAY<...>` | Direct mapping with sub-type widening |

## Partition & Clustering Conversion

- Multi-col date partitions (year/month/day) → generated `partition_date DATE`
- Multi-col year/month partitions → `PARTITION BY DATE(year, month, 1)` expression
- String partition keys (`date_ts`) → derived DATE partition column
- `CLUSTERED BY (col) INTO N BUCKETS` → `CLUSTER BY col` (bucket count dropped)

## ACID Table Handling

5 tables (`returns_ledger`, `acid_customer_address_history`, `acid_supplier_terms_history`, `acid_loyalty_points_ledger`, `acid_inventory_adjustments_log`) converted from ORC+transactional to standard BigQuery managed tables.

## Kudu Table Handling

4 Kudu tables renamed to `*_snapshot` and converted to standard BigQuery tables (Kudu PRIMARY KEY / HASH dropped).

## Deployment

```bash
# Generate concatenated DDL with variable substitution
./scripts/generate_concat_ddl.sh

# Dry-run validation
bq query --use_legacy_sql=false --dry_run < ddl/all_tables.sql

# Deploy via script
python scripts/deploy_ddl.py --env ddl/variables.env --order ddl/deploy_order.txt
```
